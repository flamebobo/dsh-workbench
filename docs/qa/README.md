## 靠 mock / 脚本验证的部分

没有对着任何真实系统运行。禅道（含回写）、GitLab（含创建 MR）、Jenkins（含触发与轮询）、更新检查、匿名上报都是 `scripts/qa/mock.mjs`，所有写请求记在 `http://127.0.0.1:4100/__log`（`evidence-double-click.txt` 是其中一份）；Sparkin 本来就是演示后端。MR 推送到的是本地裸仓库。智能体会话是真实的 DSH 会话（用 web profile 的账号模型，在 `~/.workbench-qa` 里的临时仓库上跑）。

没有验证：系统桌面通知的真实弹窗（只测了入口轮询逻辑）、`install.sh` / `install.ps1`、Windows、禅道回写和 `limit=200` 在真实禅道上的行为、DSH 桌面端本身（测试用的是 web profile）。
