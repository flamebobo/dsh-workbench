# 公司代码规范（示例）

这是一个演示用的技能包，用来说明「按项目自动挂载规范技能」。真实使用时把它换成公司自己的规范目录（设置 → 插件设置 → 技能包目录）。

## 命名
- 类名大驼峰，方法与变量小驼峰，常量全大写下划线；不用拼音和无意义缩写。
- 布尔变量以 `is` / `has` / `can` 开头。

## 异常与日志
- 不吞异常：要么处理，要么带上下文向上抛；禁止空的 catch。
- 日志写「谁、对什么、结果如何」，不打印密码、Token、身份证等敏感信息。
- 对外接口的错误码统一走项目的错误码表，不要新增裸字符串。

## 测试
- 新增或修改的逻辑要有单元测试，覆盖正常、边界、失败三类；修 Bug 先写能复现它的测试。
- 不为了通过测试而放宽断言或跳过用例。
