# Git 与合并请求规范（示例）

- 提交信息：第一行不超过 72 字，说明做了什么；正文说明为什么这样改。
- 一个提交只做一件事；不要把格式化和功能改动混在一起。
- 不直接提交到 main / master，不 force push 共享分支。
- 合并请求描述包含：背景（链接禅道单号）、改动点、测试方式与结果、风险与回滚办法。
- 合并前保证 CI 通过，至少一位同事评审。
